## Decisions

Contrary pass ran before constructive scoring. Parent-prompt contamination risk: same session that may have authored the docs is asked to refute them; primary evidence is therefore `src/`, `package.json`, `bunfig.toml`, and a fresh `bun run check` freeze, not prior chat.

Attack log (contrary cases):

- Full Ruby API mirror is false if read as 1:1. Sibling parity brief lists wrap-logger, `JsonLogging.logger`, `additional_context`, home-path redaction to `~`, Error shape `class`/`backtrace`, and UNKNOWN severity; this package does not implement those.
- "Works on Node" and Edge/Workers ALS guidance are not proven by the Bun-only check gate.
- "Aligned with the Ruby gem fallback filter" for sensitive keys is not frozen against a Ruby checkout in this repo.
- Changelog "context key cap 50" omits that `MAX_CONTEXT_SIZE` also truncates arrays; omission, not a contradiction.
- README example timestamp with six fractional digits is illustrative; clock injection yields millisecond `Date.toISOString` stamps.

Verification freeze from `bun run check` (exit 0): typecheck ok; type-coverage `(1398 / 1398) 100.00%` with `--at-least 100 --strict`; `bun test --coverage` 73 pass, All files 100.00% Funcs and 100.00% Lines; `tsc` build to `dist/`. `package.json` has no `dependencies` key (devDependencies only: `@types/bun`, `type-coverage`, `typescript`). `bunfig.toml` sets `coverageThreshold` lines, functions, and statements to 1.0.
