# Console bridge and structured install

## Participants

Andrei Makarov (@amkisko)

## Decisions

- Ship opt-in `installConsoleBridge` and `installStructuredLogging` so apps can route `console.*` through the same JSON logger.
- Document capture limits: framework CLI logs, browser console, and non-console transports stay out of scope.
- Add runnable patterns under `examples/` for Bun, Next instrumentation, and Remix handleRequest, with tests that exercise those patterns.

## Effects

- `src/console-state.ts` and `src/console-bridge.ts` added; `consoleSink` writes via bridge originals when installed to avoid re-entry.
- Public exports include bridge helpers and `consoleSinkFrom`.
- README documents full wiring and non-goals.
- Tests cover bridge install/uninstall, reentrancy, method subsets, and example boot paths.
